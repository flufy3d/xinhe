# 心核实现规划(coding agent handoff)

> **这份文档给谁**:接手心核、要动手写代码的 AI agent。
> **怎么用**:先读 [架构蓝图](心核%20架构蓝图：分层记忆与昼夜双相.md)(目标长什么样),再按本文档分阶段实现。
> **铁律**:Probe-first,**Phase N 不通过不进 Phase N+1**;每个 Phase 跑三口径 eval;卡住超 1 周走失败回退而不是继续调参。

---

## 0. 一句话目标

把心核从 v9.5(NIH skeleton 上 write 75% / **read 连续 14 轮 0%** 死锁)破局到 read ≥ 60%。
路径 = **修接口(常量 fresh_mem → learned QueryHead)+ 换机制(Hippo TTT inner SGD → Gated DeltaNet delta rule)+ 重构注入(两套抢 credit → 单次 read 两接口 MAC-R+MAL)**。三层架构 / 双 NM / 多时间尺度**不动**。

诊断细节见架构蓝图末节"为什么从 v9.5 pivot"。核心:野心(多尺度三层架构)对,病灶在 read/write 接口不对称 + Hippo 抗 distract 弱,两个**独立**问题。

## 2. 分阶段实施(每阶段 Pass 标准用**绝对值**,不用"比基线好")

### Phase 1 — Targeted Probe 基准(1-2 人天)

**目的**:把 read=0% 解构成三个独立失败模式(write 坏 / read 接口坏 / 注入坏),在 forward 单步读出,不靠 1000 步训练。

- 新建 `scripts/probe/targeted_probe.py`(~200 行)。数据生成器**在内存里产生,不入 jsonl**(避免落盘 + 与现有数据池冲突)。
- 任务:5-turn 极简 NIH(distract×N → target → query)。控制变量:`N_distract`(3→6→12)、`key_edit_distance`、`value_type`、`target_position`。
- 三诊断指标(forward 单步,no BPTT):
  ```
  write_probe   = retrieve(M_after_target, q=target_k_emb) == target_v_emb
  read_probe    = first_token(output_turn5) == target_v_first_token
  leakage_score = freq(distract_values in output_turn5)
  ```
- 在当前 v9.5 上跑 baseline(v1 N_distract=3 + v2 N_distract≥10)锚定病灶。
- **Pass**:baseline 复现 read_probe ≈ 0%(与 skeleton 一致)。不通过 → 先查 Probe 设计本身,**不要改架构**。

### Phase 2 — Query-Generation Head(2-3 人天)

- 新建 `xinhe/model/query_head.py`:
  ```python
  class QueryHead(nn.Module):
      def __init__(self, d_model, d_key, n_query=16, source="embed"):  # source 不能用 last layer(循环依赖)
          self.norm = RMSNorm(d_model); self.proj = nn.Linear(d_model, d_key * n_query)
      def forward(self, h_pre):                      # h_pre = embedding(x) 或 backbone 前 j 层
          h = self.norm(h_pre[:, -1, :])
          return self.proj(h).view(-1, self.n_query, self.d_key)  # [B, n_query, d_key]
  ```
- 改 `xinhe_model.py`:**删常量 `mem_token_init`/fresh_mem**;`mem_out = mix_gate(Hippo.retrieve(M, q), Neo)`(单次 read);MAC-R `W_mac(mem_out)` 拼输入序列前缀 + MAL `W_mal(mem_out)` 残差。
- **Phase 2 期间暂停 mix_gate**(只走 Hippo + QueryHead + MAL),纯化变量。
- 监控 q 多样性(不同 turn q 余弦距离)。
- **Pass**:Probe v2(N_distract=10)**read_probe ≥ 80%** AND **q 余弦距离均值 ≥ 0.3** AND write_probe 不降 AND 三口径全过。不通过 → 消融 source_layer / n_query,或加 contrastive loss。

### Phase 3 — Hippo 改 Gated DeltaNet(5-7 人天)

- 新建/改写 Hippo 类(`HippoDelta`,在 `neural_memory_pair.py` 或新 `hippo_delta.py`):
  ```python
  M_new = M_prev @ (I - β·kkᵀ) + β·(v ⊗ k)        # delta rule
  k = F.normalize(W_k @ x, dim=-1) / τ_k           # 严格保 β·‖k‖² < 1
  ```
- **d_key 直接起步 256,chunk_size 起步 512+**(不要省参数);第一版 PyTorch eager 验正确性,再上 `flash-linear-attention` 优化 throughput。
- 监控 M spectral norm(全程 < 10× 初始);加 early-stop。
- mix_gate 可能也暂停(只走 Hippo Delta + QueryHead + MAL)。
- **Pass**:Probe v2(N_distract=10)**write_probe ≥ 80% AND read_probe ≥ 80%** AND M spectral 稳定 AND 三口径全过。不通过 → 走失败回退,**不要 Phase 3 调参超 1 周**。

### Phase 4 — Mini-skeleton 独立验证(3-7 人天)

- skeleton 加 `--mini`:10-turn / N_distract=8 / **单一 NIH turn_kind** / 标准 curriculum 但只跑 S1 stage / chunk_size 用 Phase 3 verify 的值。
- 首次引入 LM head + curriculum,验证语言学损失下的稳定性。
- **Pass**:**read_probe ≥ 70% AND write_probe ≥ 75% AND leakage ≤ 15%** AND 三口径全过。不通过 → 回 Phase 2/3 复审,**不允许跳上全量**。

### 全量(Phase 4 通过后)

ad-hoc 先跑 N_distract=10 中变体 → 全量 skeleton(16-turn, N_distract=12+, 全 curriculum)→ 恢复 mix_gate → 验 chronological / personality 不退化。**期望 read_probe ≥ 60% 算破局**。

---

## 3. 验收:三口径 eval(每个 Phase 必跑)

1. **first-token accuracy**(贪心)— W 内有信息且能读出
2. **free-gen accuracy**(autoregressive 采样)— 部署形态下 work
3. **NM-zero baseline**(mem_out 置零,**必须 read=0%**)— 验证不是 backbone 偷偷记住

只有三口径都满足才算过 Phase。NM-zero 是关键 sanity（iter4-14 没严格执行,可能有"成功"其实是 backbone cheat）。
**eval 必须在 bf16 autocast 下跑**,否则静默 0%;`n_eps=0` 时至少 raise。

---

## 4. 失败回退(Phase 3 仍 read=0% 时)

- **Option A**:保留旧 Hippo TTT,只做 QueryHead(改造 2),验证 read 接口是否唯一病灶。A 过则 Phase 3 不必做。
- **Option B**:Hippo 用最简 Hebbian outer-product(xLSTM mLSTM 形式)作 DeltaNet 下限对照。
- **Option C**:回审 QueryHead 设计(n_query / source_layer / 训练信号不够强 → 加 contrastive loss)。
- **Option D(架构级)**:走 Larimar 路线 —— Hippo 完全换成 episodic key-value store,write-once、key-addressed。**只在 A/B/C 都失败时考虑**,此时架构蓝图作废需重写。

## 5. 关键工程纪律 & 坑(必须遵守)

| 纪律 | 为什么 |
|---|---|
| **Hippo $M$ 对 outer backprop detach** | 否则梯度通过 inner update 链炸开;但 $W_k/W_v/W_\beta$ 必须接梯度,否则 write 通路训不到 |
| **k 归一 + learnable $\tau_k$,严格保 $\beta\|k\|^2 < 1$** | 否则 $(I-\beta kk^\top)$ 不收缩,$M$ 数值爆炸 |
| **q 来自 embedding/低层,不是 last layer** | MAC-R 拼输入序列,q 依赖 last layer → 循环依赖 |
| **hook 的 6 层必须对齐 full_attention 物理索引 [3,7,11,15,19,23]** | Qwen3.5 0.8B 是 full+linear 混合(`full_attention_interval=4`,6 full + 18 linear);hook 靠 `layer.layer_type=="full_attention"` 动态判定,**别硬编码、别任选 6 层**;linear_attention 层不挂 NM(自带 FLA fast weight,会抢梯度) |
| **TBPTT 距离 ≥ write-read 距离** | 否则外层梯度教不到 write turn 上的 $M$ 更新 |
| **推理 state pad 到 turn_max_tokens** | 变长输入 NM 不更新 |
| **train 重跑 stage 必须 `--from-stage`** | train.py auto-skip 已完成 stage,否则空转 |
| **后台训练 `PYTHONUNBUFFERED=1` + `python -u`** | 否则日志不刷新,远端看不到进度 |
| **模板池 fallback 必须 raise,不能 silent** | silent fallback 把错位数据训进 jsonl,模型拿到 noise signal,看着合法实则灾难 |
| **Q-K projection 必须配 mask** | NIH distract 150:1 主导 $M$,裸开 Q-K 通路被淹 |
| **不要再单变量调参 skeleton** | chunk/tbptt/alpha/cap/Neo 都试过 14 轮全 0%,只做根因级改动 |
| **gate before scale**:max_steps ≤ 1000 + skeleton-only,S1 ≥ 90% 才加算力/数据/大 backbone | 防 marginal pass 在更难 setup 滑落 |
| **GC/SAC 在当前架构无收益** | NM bwd buffer 在 backbone hook 外,救不到 |
