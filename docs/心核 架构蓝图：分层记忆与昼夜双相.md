# 🧠 心核 架构蓝图:分层记忆与昼夜双相(目标架构)

> **状态**:目标架构(期望达成),非当前已实现状态。版本号待 Phase 1-4 验收后确定(v9.6 / v10)。
> **配套**:实施路径见 [心核实现规划.md](心核实现规划.md);本文档是"要建成什么样",实现规划是"怎么一步步建"。
>
> **相对上一代(v9.5)的三处主动 pivot**:
> 1. **read query**:常量 `mem_token_init`(退化解,read=0% 根因)→ **learned QueryHead**,从低层表示派生动态 query。
> 2. **Hippo update rule**:TTT inner SGD(`vmap(grad)` per-sample)→ **Gated DeltaNet delta rule**(显式删旧关联,抗 distract)。
> 3. **注入接口**:常量 fresh_mem prefix + α 残差两套抢 credit → **同一次 read,两个注入接口(MAC-R + MAL)**。
>
> **保留不变(心核真差异化)**:三层架构(能力/人格/操作)、多时间尺度、双 NM(Hippo 快 + Neo 慢)、昼夜双相巩固。

---

## 🌌 核心设计哲学

> **"统一记忆机制,分层时间尺度;白天觉知,夜间巩固。"**

心核的研究假设——智能从"持续状态 + 可塑性 + 多时间尺度"的统一动力系统中涌现——落到一个干净实现:

- **持续状态**:Hippo = episode 内演化的快权重矩阵 $M$;Neo = 跨 episode 持久的 `nn.Parameter`(绑定到具体人格)
- **可塑性**:Hippo 通过 delta rule 实时更新(白天);Neo 通过 outer Adam standard backprop 训练(P-cap / sleep)
- **多时间尺度**:token 级 / chunk 级 / episode 级 / persistent 级由超参(update rule、depth、retention、可训性开关)的频谱决定

模块化从两条机制(delta rule 快权重 vs backprop 慢权重)的极值采样**涌现**,不是手工拼接。

## 🏛️ 三层架构

### Layer 1:能力(Capability)── 一次训练,永久冻结

| 组件 | 形态 | 训练时机 |
|---|---|---|
| Qwen3.5 backbone | 原 base 权重(P-cap 全冻) | 永不动 |
| **QueryHead `W_q`** | 从 embedding / 低层 $h_\text{pre}$ 派生 read query(**新增**) | P-cap |
| Hippo(Gated DeltaNet)投影 | `W_k / W_v / W_β / τ_k`(线性 W 矩阵,深度 1) | P-cap |
| NeocortexBlock 全部权重 | 多头深 MLP `nn.ParameterList` + pre_norm | P-cap |
| 注入投影 `W_mac / W_mal` | mem_out → context token / 残差(**新增**) | P-cap |
| `gate_q / mem_rmsnorm` | mix_gate q proj + 输出 RMSNorm | P-cap |
| backbone LoRA(rank=16, α=32) | 24 层 q/k/v/o 适配,P-cap 完成后随 backbone 冻结 | P-cap |

**学的是**:"如何使用记忆模块",不是任何具体内容。**训完全部冻结**,作为后续所有人格的共同底座。

> ⚠️ 相对 v9.5 删除:常量 `mem_token_init`(fresh_mem 初值)——这是 read=0% 退化解的载体,被 MAC-R 动态投影取代。

### Layer 2:人格(Persona)── 每本小说一份,可热替换

| 组件 | 形态 | 何时生成 |
|---|---|---|
| Hippo state $M$ | 快权重矩阵 $M \in \mathbb{R}^{d_v \times d_k}$(episode 内演化) | 每 episode 重生 |
| Neocortex 权重 | 深 MLP `nn.Parameter`(标准 backprop 持久) | 人格注入时 backprop 训练 |
| `persona_anchor.pt` | Neocortex 权重在人格注入完成时的快照 | 注入完成后存盘,**永不覆盖** |

**存的是**:角色的认知、世界观、说话风格。**切换人格**:加载不同 `persona_anchor_<id>.pt`,毫秒级。

### Layer 3:操作(Operational)── 日常使用

| 组件 | 形态 | 行为 |
|---|---|---|
| Hippo state $M$ | 快权重 | 白天实时演化(delta rule,chunk 内并行) |
| Neocortex 权重 | `nn.Parameter` | 白天 `requires_grad_(False)` 只读;sleep 时打开 backprop |
| MAC-R / MAL 注入 | 每 turn 由 QueryHead 检索 → 两接口注入 | 跨 turn carry 走 $M$ 的 episode 内连续演化 |

## 🧮 核心数学

### 维度约定

| 符号 | 含义 | 取值 |
|---|---|---|
| $d_\text{model}$ | backbone hidden | 512 |
| $d_k$ | NM key 空间 | **256**(补偿 MLP→线性 W 容量损失) |
| $d_v$ | NM value 空间 | **128** |
| $n_q$ | QueryHead 输出 q 数 = MAC-R token 数 $n_\text{mem}$ | **16** |
| $T$ | chunk 内 token 数 | **512+**(delta rule 不需 vmap 小 chunk) |
| $j$ | $h_\text{pre}$ 取自哪几层 | embedding / 前 2 / 前 4(消融) |

### 1. Hippo(Gated DeltaNet)── 替换 v9.5 的 TTT inner SGD

**Write step**(token 级,chunk 内可并行)。输入 $x_t$ 经投影:

$$
k_t = \frac{W_k x_t}{\tau_k \|W_k x_t\|_2}, \qquad v_t = W_v x_t, \qquad \beta_t = \sigma(W_\beta x_t)
$$

$\tau_k$ 是 learnable temperature,**严格约束 $\beta_t \|k_t\|_2^2 < 1$** 防 $M$ 数值爆炸。

**delta 更新规则**:

$$
\boxed{M_t = M_{t-1}\big(I - \beta_t\, k_t k_t^\top\big) + \beta_t\, v_t k_t^\top}
$$

第一项 $(I - \beta_t k_t k_t^\top)$ 是**在 $k_t$ 方向上对旧关联的投影删除**(对治 distract 累加),第二项写入新 $(k_t, v_t)$。$M \in \mathbb{R}^{d_v \times d_k}$。

**chunk 内并行化**:Woodbury 重排,优先借用 [flash-linear-attention](https://github.com/sustcsonglin/flash-linear-attention)(Yang et al. 官方实现),**不要自己写 Triton**。第一版可用 PyTorch eager 验证正确性。

**Retrieve step**(由 QueryHead 的 $q$ 驱动):

$$
\boxed{r_h = M \cdot q^\top, \qquad q \in \mathbb{R}^{n_q \times d_k}}
$$

**边界**:chunk 边界 $M$ carry;episode 边界 $M \leftarrow 0$(可配置 carry/soft-decay 作消融)。

### 2. Neo(Backprop MLP)── 保留 v9.5

$$
r_n = \mathrm{MLP}_\theta(\mathrm{RMSNorm}(x)), \quad \theta \in \texttt{nn.Parameter},\ \text{depth}=4,\ \text{expansion}=4.0
$$

外层 Adam 直接更新 $\theta$,承载"人格 + 长程知识",episode 间持久。Neo 不存在 distract 累加问题(那是 Hippo 特性)。
**开放点**:Neo 输入是 $h_\text{pre}$(选项 A,推荐)还是共享 $q$(选项 B)。

### 3. QueryHead ── 新增模块

$q$ **必须来自 embedding / backbone 低层 $h_\text{pre}$(前 $j$ 层),不能来自 last layer** —— 否则 MAC-R 把记忆投影成 token 拼进*输入序列*会造成循环依赖(forward 没跑完就要它的输出)。

$$
h_\text{pre} = \text{Embedding}(x)\ \text{或}\ \text{backbone}_{1..j}(x), \qquad
q = \mathrm{reshape}\big(W_q \cdot \mathrm{RMSNorm}(h_\text{pre}[:, -1]),\ [B, n_q, d_k]\big)
$$

**代价**:$h_\text{pre}$ 的 query intent 比 last layer 弱;但 MAC-R token 进 backbone 后深层 attention 会基于完整上下文 refine 补偿。
**⚠ 训练信号脆弱性**:$M$ 对 outer backprop **detach**,QueryHead 学的是"统计上哪种 $q$ 最可能 retrieve 到 target",而非"target turn 的 key 信号"。**必须配 q 多样性监控**(不同 turn 派生 q 余弦距离 ≥ 0.3)防 mode collapse。

### 4. Mix Gate ── 保留 v9.5,τ 需重新校准

$$
g = \mathrm{softmax}\Big(\tfrac{1}{\tau}\big[\langle q, r_h\rangle,\ \langle q, r_n\rangle\big]\Big), \qquad \mathrm{mem\_out} = g_0 r_h + g_1 r_n
$$

Hippo 输出从 "MLP_W 输出" 变成 "$M \cdot q^\top$",量级/方差变了,$\tau$ 需重调;entropy regularizer 防 gate 塌成 one-hot。
**Phase 2/3 期间建议暂停 mix_gate**(只走 Hippo + QueryHead + MAL),纯化变量,验证后再恢复双路。

### 5. 注入接口 ── 同一次 read,两个 injection interface

v9.5 病灶是 MAC(常量 fresh_mem)与 MAL 是**两套独立 read path 抢 credit**。改为 **单次 read,两接口注入**:

```
q       = QueryHead(h_pre)              # 低层派生
r_h     = Hippo.retrieve(M, q)          # M · q^⊤
r_n     = Neo(...)
mem_out = mix_gate(r_h, r_n)            # ← 唯一一次 read

mac_tokens = W_mac(mem_out)             # [B, n_mem, d_model]  context 接口
mal_vec    = W_mal(mem_out)             # [B, T 或 1, d_model]  残差接口
```

**MAC-R**(Memory-as-Context, Retrieved):`mem_out` 经 $W_\text{mac}$ 投影成 $n_\text{mem}$ token,拼进 backbone *输入序列*:

$$
\text{input} = [\underbrace{\text{persona tokens}}_{\text{三层架构}};\ \underbrace{W_\text{mac}(\text{mem\_out})}_{n_\text{mem}\ \text{token}};\ \underbrace{x}_{\text{当前 turn}}]
$$

与 v9.5 MAC 的**本质区别**:不再是常量 `fresh_mem`,而是动态 retrieve 投影 —— 退化解病灶消除,backbone attention 自己决定怎么用(content-based)。

**MAL**(Memory-as-Layer):同一个 `mem_out` 经 $W_\text{mal}$ 投影成残差,注入中后层:

$$
\boxed{h_l \leftarrow h_l + \alpha \cdot W_\text{mal}(\text{mem\_out}), \quad \alpha = \sigma(\alpha_\text{logit}),\ \text{起步}\ \sigma(-3) \approx 0.05}
$$

**两接口分工**:MAC-R 让 backbone *主动* attend(强表达,要过 attention);MAL 是 *被动* 残差(直接但固定)。可消融"只 MAC-R / 只 MAL / 并用"。

─────────────────────────────────────────────────────                    │
backbone 输入 = [persona tokens; mac_tokens; x]                           │
                │                                                         │

                │   k = norm(W_k x)/τ_k,  v = W_v x,  β = σ(W_β x)

## 🎓 训练流程

### 梯度通路

| 模块 | outer grad | 备注 |
|---|---|---|
| backbone(LoRA) | ✓ | P-cap 内开,P-cap 完冻结 |
| Neo $\theta$ | ✓ | 标准 backprop |
| QueryHead $W_q$ | ✓ | 经 MAC-R + MAL → mem_out → $r_h$ → $q$ |
| MAC-R 投影 $W_\text{mac}$ | ✓ | 经 backbone attention 反传 |
| MAL 投影 $W_\text{mal}$ | ✓ | 经残差 |
| Hippo $W_k, W_v, W_\beta, \tau_k$ | ✓ | 经 $r_h = Mq^\top$ → $M$ → write step |
| **Hippo $M$(state)** | **detach** | ★ 核心 train discipline,否则梯度通过 inner update 链炸开 |
| mix_gate τ / MAL α_logit | ✓ | learnable scalar |

### Auxiliary losses

$$
\mathcal{L}_\text{total} = \mathcal{L}_\text{LM} + \lambda_\text{div}\mathcal{L}_\text{q-div} + \lambda_\text{ent}\mathcal{L}_\text{gate-ent} + \lambda_\text{aux}\mathcal{L}_\text{NM-aux}
$$

- $\mathcal{L}_\text{q-div} = -\lambda_\text{div}\,\mathbb{E}_{i\neq j}[1 - \cos(q^{(i)}, q^{(j)})]$:强制不同 turn 的 $q$ 分离,防 mode collapse
- $\mathcal{L}_\text{gate-ent} = -\lambda_\text{ent} H(g)$:防 gate 塌
- $\mathcal{L}_\text{NM-aux}(可选)$:write/read probe loss,直接给 Hippo 正向信号

### Curriculum(三层架构 sleep cycle)

```
Phase A: P-cap(能力训练)
  backbone LoRA + Neo θ + Hippo W_k/W_v/W_β + QueryHead W_q + W_mac/W_mal 全开 grad
  任务:NIH skeleton(主)+ chronological + personality

Phase B: 人格注入(persona injection)
  冻 backbone(LoRA off);继续训 Neo θ + QueryHead;Hippo M 每新 persona reset
  训完存 persona_anchor.pt

Phase C: 日常 sleep(daily use)
  全冻除 Hippo M(test-time learning);replay buffer 周期激活 backprop 防漂;persona_anchor 锚定 Neo
```

## 🔮 推理流程

```
state = load_persona_anchor()                 # Neo θ + 冻结 backbone
for turn in conversation:
    x = pad_to_turn_max(tokenize(user_input)) # ★ 变长输入 NM 不更新,必须 pad 到 turn_max_tokens
    h_pre = embedding(x)                       # 或 backbone 前 j 层
    q = W_q · RMSNorm(h_pre[:, -1])
    r_h, r_n = M @ q^⊤, MLP_θ(h_pre[:, -1])
    mem_out = mix(r_h, r_n)
    h = backbone([persona_tokens, W_mac(mem_out), x])
    h[layer=l] += α · W_mal(mem_out)           # MAL
    M = delta_chunk_update(M, k, v, β)         # test-time learning,供下一 turn
    yield decode(final_hidden)
```

| state 元素 | 生命周期 | 持久化 |
|---|---|---|
| backbone(+ LoRA) | 永久 | model checkpoint |
| Neo $\theta$ | per-persona | persona_anchor.pt |
| Hippo $M$ | per-episode(可选 carry) | 内存,episode 结束 reset |
| QueryHead $W_q$ / mix τ / MAL α / $W_\text{mac}$ / $W_\text{mal}$ | 永久 | model checkpoint |

**多 persona 切换**:load `persona_anchor_<id>.pt` → Neo θ;reset $M \leftarrow 0$;不动 backbone / QueryHead。

| 参数 | 推荐起步 | 说明 |
|---|---|---|
| $d_k$ / $d_v$ | 256 / 128 | Hippo 容量,**直接起步 256 不要省参数** |
| $n_q = n_\text{mem}$ | 16 | QueryHead 输出 = MAC-R token,消融 4/8/16 |
| chunk_size | 512+ | delta rule 不需小 chunk |
| QueryHead source 层 $j$ | embedding / 前 2 / 前 4 | 消融点 |
| MAL α_logit init | $\sigma^{-1}(0.05)\approx-3$ | 残差起步保守 |
| MAL 注入层 $l$ | -3 / -4 | 消融 |
| mix_gate τ | 网格搜索 | Hippo 输出分布变,需重校准 |
| $\lambda_\text{div}$ / $\lambda_\text{ent}$ | 0.01–0.1 grid / 0.01 | q 多样性 / gate 熵 |
| LoRA rank / α | 16 / 32(q/k/v/o) | P-cap 完冻 |

| 监控指标 | 期望 / 阈值 | 失败信号 |
|---|---|---|
| **q 余弦距离(不同 turn)** | ≥ 0.3 | < 0.3 → QueryHead mode collapse |
| **$M$ spectral norm** | 全程 < 10× 初始 | 暴涨 → $\beta\|k\|^2$ 约束失效,W 爆炸 |
| mix_gate 熵 $H(g)$ | > 0.4(二元最大 0.693) | 单边塌缩 → 加大 λ 熵 |
| MAL $\alpha.\sigma()$ 训后 | > 0.05 | ≈0 → mem 通路 collapse |
| read_probe(NM-zero 对照) | NM-zero 必须 ≈0% | 否则 backbone 在 cheat |

## ⚠️ 风险与防护

| 风险 | 防护 |
|---|---|
| **QueryHead mode collapse**(W detach 训练信号脆弱) | q 多样性监控 + $\lambda_\text{div}$ contrastive;Phase 2 必须验 N_distract ≥ 10 |

## 📎 背景:为什么从 v9.5 pivot(诊断摘要)

v9.5 在 NIH skeleton 上 **write probe 75% 但 read probe 连续 14 轮 0%**,NM-on 与 NM-zero 无差。两层根因:

1. **接口病灶(read/write 不对称)**:MAC `fresh_mem` 是**无 query 的常量定址**退化解,几何上 $W \cdot q_\text{const}$ 不可能 retrieve 出特定 turn 信息 —— write 涨与否完全独立于 read 能否 retrieve。→ **QueryHead 修接口**。
2. **机制弱点(抗 distract 弱)**:Hippo inner-SGD 误差项虽胜过纯 Hebbian,但**无显式"删旧关联"机制**,NIH 150:1 distract 比例下 W 被淹。→ **Gated DeltaNet 换机制**(delta rule 显式投影删除旧 key 关联)。

野心(多尺度三层架构)与病灶(接口退化)在同一架构里共存不矛盾 —— 是接口设计与机制设计两个独立问题。修接口 + 换机制,野心不动。
